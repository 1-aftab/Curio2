HOW IT WORKS

Three steps. One exit.

01

Set it.

A time, a repeat, a sound. Or a quick alarm from home: 15 minutes, 30 minutes, or an hour.

02

It rings.

Over the lock screen, even if the app is closed. Power, Home, and a swiped notification bring the challenge back. The tone keeps going.

03

Solve it.

Math, a memory sequence, or a phrase. That is the dismiss button. A timer can be tapped away. An alarm cannot.

THE APP

What you actually get.

Challenges
Arithmetic, sequence memory, or typing a phrase. Easy, medium, or hard. Turn on more than one and Curio picks at random each ring.
Power button
Turns the screen off for a moment, at most. It does not dismiss the alarm. Force-stop in system Settings is the one escape Android still allows.
Snooze
Off on alarms you already saved. New alarms can snooze 5, 9, or 15 minutes, up to three times. Kiosk mode never snoozes. After the last one, only the challenge stops it.
Quick alarms
15 minutes, 30 minutes, or 1 hour from the home screen. One-shot, with a single 9-minute snooze.
Wake streak
Consecutive days you solved the challenge. Snooze does not count. Dismissing a timer does not count.
Alert
Sound and vibration, sound only, or vibration only. Per alarm, and for the timer. Import your own audio. Volume can fade in.
Stopwatch
Laps, with fastest and slowest marked. Keeps the right time if you leave the app.
Timer
Presets or your own length. Rings with Curio closed or the phone locked. One tap stops it. No challenge.
Appearance
System, Light, or Dark. Black and white either way, including the ringing screen and the system bars.
Privacy
No account, no ads, no tracking. Notifications, exact alarms, full-screen alerts, and an optional battery exception are explained before they are asked. They exist so the alarm can ring.

INSTALL

The file, then the phone.

  1. Press Download. The file is CurioAlarm.apk, version 1.3.
  2. On a computer, send that file to the Android phone. On the phone, open it from the browser or the Files app.
  3. If Android blocks it, allow installs from that app. The phone calls these “unknown apps.”
  4. Play Protect may warn you because this is not the Play Store. Curio is a direct install from this page.
  5. Open Curio. The consent screen comes before any permission. The checkbox is required.
  6. Allow exact alarms if you want the minute you set, not “sometime soon.”

If it will not install

Uninstall the older Curio Alarm first. These builds are not always signed with the same key, and Android refuses the update when the signature changes.
